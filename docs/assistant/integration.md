# Bedrock AI 어시스턴트 준비

## 역할 구분

- **규칙 기반 튜터**: FastAPI가 C/ASM/CRT 및 사이클 이벤트 해설을 생성한다. 외부 모델이 필요 없다.
- **AI 어시스턴트**: 로그인한 사용자의 대화 텍스트를 Bedrock에 보내 SSE로 답한다. `app/services/assistant`에 분리한다.
- **실행 컨텍스트 분석기**: 코드·전체 실행 결과·선택한 사이클을 읽어 AI에 필요한 맥락을 구성하는 미래 모듈이다. `app/schemas/execution_context.py`에 인터페이스만 정의하며 구현과 연결은 보류한다. 조회 시 소유권 검사가 필요하다.

## 비활성 상태 배포

`ASSISTANT_ENABLED=false`가 기본값이며 배포에서도 유지한다. 사용량 테이블 마이그레이션은 앱 시작 시 적용한다. 비활성 채팅 요청은 로그인 검사 후 HTTP 503 `AGENT_NOT_CONFIGURED`를 반환하며 모델 호출 및 사용량 차감을 하지 않는다.

- `GET /api/v1/assistant/status`: 활성화 플래그만 반환한다. 실제 모델 접근 성공을 보장하는 상태 검사는 아니다.
- `GET /api/v1/assistant/transport-check`: 공개된 고정 진단 이벤트 두 개를 0.5초 간격으로 반환한다. 질문·사용자 데이터·DB·Bedrock을 사용하지 않으며 실제 AI 답변이 아니다. 브라우저/CloudFront/nginx 경유 SSE 전달을 검증하기 위한 경로다.
- `POST /api/v1/assistant/chat`: 기존 로그인 토큰을 사용한다. 활성화 후에만 사용자별 사용량을 예약하고 모델을 호출한다.

## 제한 및 취소

UTC 기준 사용자당 50회/일, 요청 간 10초, 최대 20개 메시지, 각 8,000자·합계 24,000자, 최대 출력 2,048토큰, 전체 응답 60초 제한이다. 실패·취소한 모델 요청도 사용량에 포함된다. DB에는 대화 본문을 저장하지 않는다.

SDK 연결 5초/읽기 20초, 최대 2회 시도, 워커당 최대 8개 모델 호출 스레드, 유한 큐 32개를 사용한다. 브라우저 연결 중단 시 upstream을 닫고, 연결 중 취소되면 SDK 반환 직후 닫는다. 10초마다 keepalive를 보낸다. 계정 전체 금액 상한은 별도 구현/설정이 필요하다.

이번 비활성 배포는 애플리케이션만 갱신한다. CloudFormation의 Bedrock 권한·환경 매개변수 변경은 준비안이며 아직 운영 스택에 적용하지 않는다. 현재 운영 환경에 별도 활성화 값이 없는지 확인하고 코드 기본값 false를 유지한다.

## 승인 후 활성화

1. 계정 `242925688392`, 서울 `ap-northeast-2`에서 `anthropic.claude-sonnet-5`의 실제 호출 성공을 확인한다.
2. CloudFormation 템플릿을 검증하고 변경 세트를 검토해 적용한다. 환경 스택 갱신 시 현재 배포 중인 VersionLabel을 보존하여 초기 버전으로 되돌아가지 않도록 한다. 운영 역할에 해당 서울 모델의 `bedrock:InvokeModelWithResponseStream` 권한과 사용량 테이블이 준비됐는지 확인한다.
3. `AssistantEnabled=true`로 변경하고 로그인된 실제 채팅의 정상 응답·취소·한도를 확인한다.
4. 문제가 있으면 false로 되돌린다. 모델명/리전을 바꿀 때는 앱 설정과 IAM 리소스 범위를 함께 변경한다.

API 키를 프론트에 전달하지 않는다. 배포는 인스턴스 역할, 로컬 검증은 `archreactor-new` 프로파일을 사용한다. 실제 모델은 계정 접근 제한으로 성공 응답이 아직 확인되지 않았다.
